03 / ANALYSIS

把数字，
变成清晰的结果。

几个轻量的计算器，一张随手生成的趋势图。输入数据，查看结果，随用随走。

增长率

比较两个期间的变化。上期金额须大于零，增长率为（本期 − 上期）÷ 上期。

预算差异

查看实际与预算的金额差和差异率。正值表示高于预算，不直接等同于有利差异。

盈亏平衡

按单一产品、固定单价和单位变动成本计算保本销量。销量按完整单位向上取整。

现金流折现

期初投入在第 0 年，每行现金流在对应年末发生。正数为流入，负数为流出。

最多 100 年；期初投入不要重复写入这里。

趋势图

每行输入「期间,金额」，支持逗号或制表符分隔；不要包含表头或千位分隔符，最多 80 行。

计算和图表都在你的浏览器中完成，不上传、不保存输入。金额使用同一币种和单位；显示值四舍五入到两位小数，模型假设见各工具说明。
